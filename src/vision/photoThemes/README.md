These three theme definitions were supplied by the user in Claude's Vision Forge project:
`packs/vision2027/theme.json`, `packs/travel/theme.json`, and `packs/diaries/theme.json`.

The JSON preserves its palettes, titles, labels, quotes, and search keywords. VisBo uses
the palettes and copy locally; it does not download stock photos or run background removal.
`photoLayout.ts` adapts Forge's scrapbook, recursive collage partition, and sticker lettering
recipes to 1–12 selected uploads and the current board dimensions. Decorations are native,
editable canvas items. Preview and Apply share the same composition and canvas renderer.
